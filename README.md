# 計數本

多人聚會分帳工具：記低邊個找數、邊個有份，自動計每人結餘同最少轉帳次數嘅埋單方案。支援人民幣（¥）自動換算做港幣（$），仲可以一鍵匯出做有公式嘅 Excel／Google Sheet 檔案，方便核對。

用 GitHub Pages host，純前端網頁，資料淨係存喺瀏覽器本機（localStorage），唔會上傳去任何伺服器。

## IG Post Generator

喺瀏覽器整有設計感嘅 IG 貼文圖，做完直接匯出 PNG。同樣係純前端單一 HTML 檔，唔會上傳任何嘢去伺服器。

- **尺寸**：直式 4:5（1080×1350）、正方形、橫式 5:4、限時動態 9:16、橫式 1.91:1
- **45 款版面**，每 9 個一頁可左右滑：基本 → 幾何 → 內容型 → Fancy → 手寫風
- **配色**：9 組預設 ＋ 自選配色（漸層、文字、強調色、色塊）
- **背景**：漸層、上傳照片（可縮放、拖曳定位、暗化、漸層遮罩）
- **插圖**：加入圖片並可**退地**（去背景，容差＋邊緣柔化）、圓形／圓角遮罩、輪廓陰影
- **裝飾**：16 款手繪風線條同圖示（波浪線、手繪圈、箭頭、閃光、膠紙⋯⋯）
- **文字**：18 款字型（中英分組，含繁體手寫霞鶩文楷同多款 playful 手寫體）、直排、描邊、光暈（可選色）、底色標記
- **編輯**：拖曳定位＋吸附輔助線、方向鍵微調、圖層鎖定、多選對齊／均分
- **多頁**：最多 10 頁輪播；手機版用 IG 式圓點導覽，掃到最尾再向左拉即新增一頁
- **輸出**：撳 Output 會直接開圖，手機長按即可存入相簿；亦可儲存做 PNG 檔

字型由 Google Fonts 載入，第一次開需要網絡。
